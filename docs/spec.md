# TimeCalc 外部仕様書

TimeCalc は、時間（`H:MM` 形式）と数値を混在させた式を計算できる電卓アプリです。
「1時間30分」のような時間の量を、他の数値と同じように四則演算に使えます。

本書はユーザーから見た振る舞い（画面・操作・計算結果）を定めるものであり、
内部実装（データ構造やコードの構成）には立ち入りません。

## 1. 画面構成

画面は上から次の2つの領域で構成されます。

1. **表示部**
   - **数式表示**：これまでに入力した数式を表示する。右寄せで、点滅するカーソルが編集位置を示す。
   - **結果表示**：`=` を押して計算した結果、またはエラーメッセージを表示する。何も計算していない間は空欄。
2. **キーパッド**：数字・記号・演算子・編集操作のボタンを並べたグリッド。

### キー一覧

| 段 | ボタン |
|---|---|
| 1 | `AC`（全消去） / `←`（カーソル左移動） / `→`（カーソル右移動） / `⌫`（1文字削除） |
| 2 | `00` / `(` / `)` / `÷` |
| 3 | `7` / `8` / `9` / `×` |
| 4 | `4` / `5` / `6` / `−` |
| 5 | `1` / `2` / `3` / `+` |
| 6 | `0` / `：`（時分の区切り） / `.`（小数点） / `=`（計算実行） |

## 2. 値の種類

TimeCalc が扱う値は次の2種類です。

- **時間**：`H:MM` の形式で入力する（例：`1:30` は1時間30分、`0:05` は5分）。時（`H`）は桁数の制限なく入力できる。
- **数値**：整数または小数（例：`7`、`3.5`）。

同じ数式の中に、時間と数値を組み合わせて記述できます（例：`1:30 × 2`）。

## 3. 入力の操作

- 数字ボタン（`0`〜`9`、`00`）を押すと、カーソル位置に数字が挿入される。
- `：` を押すと、入力中の値に時分の区切りが挿入され、時間の値として入力できる（例：`1` `：` `3` `0` → `1:30`）。
- `.` を押すと、入力中の値に小数点が挿入され、小数の数値として入力できる。1つの値の中で `：` と `.` を混在させることはできない。
- `+` `−` `×` `÷` を押すと、カーソル位置に演算子が挿入される。
- `(` `)` を押すと、カーソル位置に括弧が挿入される。式の優先順位を指定するために使う。
- `←` `→` を押すと、数式表示内でカーソルが1文字ずつ移動する。
- 数式表示エリアを直接タップ（クリック）すると、その位置にカーソルが移動する。
- `⌫` を押すと、カーソルの直前の1文字を削除する。
- `AC` を押すと、数式・結果・カーソル位置がすべて消去され、初期状態に戻る。

### 入力できない操作（誤入力の防止）

以下のような、成立しない式につながる入力は行えない（ボタンを押しても何も起こらない）。

- 演算子を連続して入力すること（例：`1:00 + × `）。ただし `−` は直後に単項マイナス（符号）として続けて入力でき、`1:00 + -3:00` のような表現ができる。
- 数式の先頭やカッコの直後にいきなり `×` `÷` を入力すること（`−` による符号指定を除く）。
- 数値や `)` の直後に、演算子を挟まずに数字や `(` を入力すること（暗黙の乗算はできない）。
- 開き括弧と対応しない閉じ括弧を入力すること、あるいは対応する開き括弧がないまま `)` を入力すること。
- 1つの値の中に `：` や `.` を2つ以上入力すること、また時分の区切りと小数点を同じ値に混在させること。
- 時分の区切り `：` の前に数字が1つも無い状態で `：` を入力すること（分だけの入力はできない。`0:05` のように時を明示する）。

## 4. 計算の実行（`=`）

- `=` を押すと、その時点の数式を計算し、結果表示に答えを表示する。
- 数式の途中に閉じられていない `(` が残っている場合は、自動的に `)` を補って計算する。
- 数式が空、または末尾が演算子のままなど、計算を完了できない状態では `=` を押しても何も起こらない。

### 計算後の続け入力

- `=` を押した直後に演算子（`+` `−` `×` `÷`）を押すと、直前の結果を先頭にした新しい式として続けて計算できる（例：`1:00 + 1:00 =` → `2:00` の後に `+ 3:00 =` → `5:00`）。
- `=` を押した直後に `⌫`、`←`、`→`、または数式表示のタップを行うと、結果表示が消えて編集モードに戻り、直前の数式をその場で編集できる。
- `=` を押した直後に数字などを押すと、新しい数式の入力として最初からやり直しになる。

## 5. 計算のルール（演算の組み合わせ）

時間どうし・数値どうし・時間と数値の組み合わせによって、計算できる演算とできない演算があります。

| 演算 | 時間 op 時間 | 時間 op 数値 | 数値 op 時間 | 数値 op 数値 |
|---|---|---|---|---|
| `+` `−` | 時間になる | エラー | エラー | 数値になる |
| `×` | エラー | 時間になる | 時間になる | 数値になる |
| `÷` | 数値になる（時間の比） | 時間になる | エラー | 数値になる |

- 時間どうしの割り算（例：`3:00 ÷ 1:30`）は、時間同士の比率を表す数値になる（結果は `2`）。
- 0で割る演算（時間を数値0で割る、時間を時間0:00で割る、数値を数値0で割る）はエラーになる。
- 上記の表にない組み合わせ（時間と数値の加減算、時間どうしの掛け算、数値を時間で割る等）は、いずれもエラーになる。
- 単項マイナス（式の先頭や演算子・開き括弧の直後の `−`）は、時間・数値のどちらの値にも使え、符号を反転させる。
- 括弧 `( )` により、四則演算の優先順位を明示的に指定できる。括弧を使わない場合の優先順位は、通常の算数と同じく `×` `÷` が `+` `−` より先に計算される。

## 6. 結果の表示形式

- **時間の結果**は `H:MM` 形式で表示する。負の時間は先頭に `-` が付く（例：`-0:01`）。
- 計算の途中経過で分未満の端数（秒単位）が生じ、それが最終結果にも残っている場合、結果表示の「分」の部分に下線が表示される。これは、表示上は分単位に丸められているが、実際にはそれより細かい端数を含んでいることを示す。
- **数値の結果**は、整数はそのまま、小数は小数点以下を含めて表示する。計算誤差によるごく微小な小数のずれは丸めて表示する。

## 7. エラー表示

- 計算できない式（型の組み合わせが誤っている、0で割っている等）に対して `=` を押すと、結果表示にエラーメッセージが表示される。
- メッセージの内容は、エラーの原因を表す日本語の短い説明文（例：「時間と数値は加算できません」「0で割ることはできません」）。
- エラー表示中でも、数式表示は入力した内容を保ったまま表示され続ける。`⌫` 等で編集モードに戻って修正できる。

## 8. 数式の表示上の整形

- 入力した `×` `÷` `+` `−` の各演算子は、数式表示上では前後に半角スペースを入れて表示される。ただし単項マイナス（符号）は詰めて表示される。
- 入力そのもの（`×` `÷` の全角記号や桁数など）は変更されず、あくまで見やすさのための表示上の整形。

## 9. インストール（PWA）

- TimeCalc はPWA（Progressive Web App）として、ホーム画面への追加やアプリらしい単独ウィンドウでの起動に対応する。

## 10. 現時点での制限事項

- 秒単位の入力・表示には対応していない（計算内部では端数として保持されるが、入力・表示は `H:MM` 単位のみ）。
- キーボードからの入力には対応していない（ボタン操作のみ）。
